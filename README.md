# Android From Zero

Building an Android APK completely from scratch, with no IDE, no Android Studio, no project templates, and no preconfigured development environment.

The goal is to understand and implement every step of the Android application development and build process manually, starting from an empty repository and working toward a fully functional APK.

## Philosophy

- No IDEs or graphical development tools.
- No prebuilt project scaffolding or templates.
- Manual configuration and build processes.
- Full control over source code, dependencies, and tooling.
- Learn how Android applications work under the hood.
